# 唐老师 AIGC 资料交流

这是一个用于整理、分享和交流 AIGC 相关资料的仓库，适合用来沉淀学习笔记、工具清单、案例资源、提示词经验和实践教程。

## 仓库用途

- 汇总 AIGC 学习资料、教程和参考链接
- 记录 AI 绘图、AI 视频、AI 音频、AI 写作等工具的使用经验
- 整理可复用的提示词、工作流和实操案例
- 分享适合教学、内容创作、项目实践的 AIGC 资源
- 方便团队或同学之间持续交流、补充和更新资料

## 推荐内容分类

后续可以按照下面的方向逐步补充内容：

```text
.
├── tools/          # AIGC 工具清单与使用说明
├── prompts/        # 提示词模板与案例
├── tutorials/      # 教程、操作步骤、学习笔记
├── cases/          # 项目案例、作品展示、复盘记录
├── assets/         # 图片、音频、视频等素材资源说明
└── links/          # 推荐网站、文章、模型和平台链接
```

## 可交流的主题

- AI 绘画与海报设计
- AI 视频生成与短剧创作
- AI 配音、音乐与语音克隆
- AI 写作、脚本、文案与教学内容生成
- AIGC 工具对比与使用体验
- 提示词工程与自动化工作流
- AIGC 在课堂、培训、社群和项目中的应用

## 贡献方式

欢迎把有价值的资料整理到仓库中。建议提交内容时包含：

1. 资料名称
2. 资料链接或文件位置
3. 适用场景
4. 使用方法或简短说明
5. 个人体验、注意事项或推荐理由

## 更新建议

为了让资料更容易查找，建议后续保持以下习惯：

- 文件名尽量清晰，能直接看出主题
- 同类资料放在同一个目录下
- 链接型资料注明来源和用途
- 工具类资料可以补充费用、平台、优缺点和适用人群
- 重要内容优先写成 Markdown，方便阅读和维护

## 说明

本仓库主要用于 AIGC 学习交流和资料沉淀。内容可持续迭代，欢迎不断补充新的工具、案例、教程和经验。
